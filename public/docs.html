MeetSpaceSync API

Base URL: http://127.0.0.1:4300/api  ·  Spec: openapi.json  ·  App: open the UI

New to API testing? Start here

  1. Start the server. Run node server.js. The Base URL above should answer.
  2. Get a token. Click the green Authorize button, press "Log in as admin", then "Close". The username and password are already filled in for you.
  3. Open an endpoint. Click any row below to expand it and read what it does.
  4. Try it. Press "Try it out", then "Execute". Bodies are prefilled with working values, including a Booking Date set to tomorrow, so the first call succeeds.

Every error uses the same envelope

{ "error": { "code": "VALIDATION_ERROR", "message": "Please correct the highlighted fields.", "details": { "fieldErrors": { "bookingDate": "Choose a valid Booking Date." } } } }
  • 401 UNAUTHORIZED means no token was sent. Press Authorize first.
  • 400 VALIDATION_ERROR carries details.fieldErrors, one entry per field that failed.
  • bookingDate must be YYYY-MM-DD and cannot be in the past, which is why the sample body uses tomorrow.

Business rules worth testing

  • Overlapping Bookings for the same Meeting Room return 400 VALIDATION_ERROR with details.fieldErrors.roomId. Check the slot first with GET /availability.
  • An Administrator must provide a Cancellation Comment when cancelling a Booking.
  • A Meeting Room with a future active Booking returns 409 ROOM_HAS_FUTURE_BOOKINGS when deactivation is attempted. Cancel the Booking first, then deactivate with a Deactivation Comment.
  • Attendee count cannot exceed Room capacity, Booking end time must be later than start time, and the duration cannot exceed 4 hours.
  • POST /reset and PATCH /rooms/{roomId} need the admin account; the user account receives 403 FORBIDDEN.
